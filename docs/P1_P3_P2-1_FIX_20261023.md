## 一、改动清单

### P1 — Multiwfn 版本探测编码异常（已修复并实测）
- 文件：`backend/postprocess/multiwfn.py`，函数 `probe_version()`
- 问题：原 `subprocess.run(..., text=True)` 在中文 Windows 下读 Multiwfn banner，后台 reader 线程抛 `UnicodeDecodeError`，且 capabilities 报 `version_matched=false`。
- 改法：
  - 改为二进制读（`input=b"q\n"`，不用 `text=True`）；
  - 只保留可打印 ASCII 字节（0x20–0x7E）再解码，GBK 中文不再触发异常；
  - 正则先匹配 `Version X.Y`（banner 实际写法是 "Version 3.8, update date: ..."），再回退 `Multiwfn X.Y`；只取主版本号，不碰 update date 字段。
- 实测：`probe_version()` 稳定返回 `'3.8'`，与 profile `3.8` 匹配，**无解码异常**。
